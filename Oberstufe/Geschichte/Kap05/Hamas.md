# Definition 
Das Wort Hamas ist eine Abkürzung für "islamische Widerstandsbewegung". Es bedeutet auf Arabisch auch "Eifer", Die [[Terrorismus|Terrororganisation]] kämpft für die Errichtung eines [[Islam|islamischen]] Staates [[Palästina]].
