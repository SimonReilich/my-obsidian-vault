#Oberstufe #Physik

# Definition

Induktion I: Bewegt sich ein [[Leiter]] relativ zu einem [[Magnetfeld]], so wird in diesem ein Strom induziert

Induktion II: Ändert sich das [[Magnetfeld]] um einen [[Leiter]], so wird in diesem ein Strom induziert

# Induktionsspannung

Für die Induktionsspannung $U_{ind}$ in einer Spule gilt:
$$ U_{ind} = -n * \dot{\Phi} = -n * (\dot{B} * A + B * \dot{A}) $$ $n$ : Windungszahl, $\dot{\Phi}$ : Ableitung des [[Magnetischen Fluss]]
