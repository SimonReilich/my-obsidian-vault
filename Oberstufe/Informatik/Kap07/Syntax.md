#Oberstufe #Informatik
# Definition
Als Syntax bezeichnet man den Aufbau einer (formalen) [[formale Sprache|Sprache]]. Die Syntax trifft allerdings keinerlei Aussagen über denn Sinn von einzelnen Wörtern einer Sprache. So kann ein Wort / Satz einer Sprache durchaus syntaktisch korrekt aber völlig sinnlos ([[Semantik|semantisch]] falsch) sein.
