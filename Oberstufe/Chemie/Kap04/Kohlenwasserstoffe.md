#Oberstufe #Chemie #Q12 
# Halogenierung von Alkanen

(Bsp.: Brom, auch andere Halogene sind möglich)

1. Startreaktion (Radikalbildung)
$\ce{Br2 -> Br + Br}$ (Bildung des Brom-Radikals durch Licht / Wärme)
-> Homolytische Bindungsspaltung (Homolyse)

2. Kettenreaktion
$\ce{RCH3 + Br -> HBr + RCH2}$ (Alkan-Radikal)
$\ce{RCH2 + Br2 -> RCH2Br + Br}$ (1-Brom-Alkan und Bromradikal)

3. Kettenabbruch (Rekombination)
$\ce{Br + Br -> Br2}$ (Brommolekül)
$\ce{RCH2 + Br -> RCH2Br}$ (1-Brom-Alkan)
$\ce{RCH2 + H2CR -> RCH2CH2R}$ (2n-Alkan)

Auch mehrfache Bromierung möglich, alle Wasserstoffatome sind mögliche Angriffspunkte

# Halogenierung von Alkenen

Im Alkenmolekül wird ein Halogenmolekül an die Doppelbindung angelagert (= addiert)
-> elektrophile Addition

1. Polarisierung
$\ce{H2C2HR + Br2 -> H2C2HR + Br^\delta + + Br^\delta -}$ (Übergangszustand $\pi$-Komplex)
2. Heterolytische Bindungsspaltung (Heterolyse) und elektrophiler Angriff
$\ce{H2C2HR + Br^\delta + + Br^\delta - -> H2CBrCHR + Br-}$ (Zwischenprodukt $\sigma$-Komplex) 
-> ringförmiges Bromoniumion
3. nukleophiler Rückseitenangriff
$\ce{H2CBrCHR + Br- -> H2BrC2BrHR}$ (1, 2-Dibromalkan)

# Halogenkohlenwasserstoffe

- Fluorchlorkohlenwasserstoffe, kurz FCKW, sind [[Kohlenwasserstoffe]], bei denen Wasserstoffatome durch die Halogene Chlor und Fluor substituiert wurden. Sie sind eine Untergruppe der Halogenkohlenwasserstoffe.
- Nutzung: Kältemittel, Treibgas für Sprühdosen
- Vorteile: Effizientes Kühlmittel, unbrennbar, sehr stabil
- Nachteile: Zerstörung der Ozonschicht, Treibhausgas
- Abbau: Photolyse - UV-Strahlung bricht die chemische Struktur von FCKW auf
