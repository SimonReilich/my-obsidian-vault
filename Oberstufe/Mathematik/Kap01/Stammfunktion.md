#Oberstufe #Mathematik 
# Definition
Man nennt eine [[Differenzierbarkeit|differenzierbare]] [[Funktion]] $F$ eine Stammfunktion der [[Funktion]] $f$, wenn $f$ die [[Ableitung|Ableitungsfunktion]] von $F$ ist, d.h. wenn für jedes $x \in D_f$ gilt: $F'(x) = f(x)$. Zu einer Potenzfunktion $f(x) = x^n$ ist $F(x) = \frac{1}{n + 1}x^{n + 1}$ eine Stammfunktion.
