# Satz
$$(f(x) * g(x))' = f'(x) * g(x) + f(x) * g'(x)$$

# Beweis
$(f(x_0) * g(x_0))' = \lim_{x \to x_0} \frac{f(x)g(x) - f(x_0)g(x_0)}{x-x_0} = \lim_{x \to x_0} \frac{f(x)g(x) - f(x_0)g(x) + f(x_0)g(x) - f(x_0)g(x_0)}{x-x_0} =$ 
$= \lim_{x \to x_0} \frac{f(x)g(x) - f(x_0)g(x)}{x-x_0} + \frac{f(x_0)g(x) - f(x_0)g(x_0)}{x-x_0} = \lim_{x \to x_0} g(x) * \frac{f(x) - f(x_0)}{x-x_0} + f(x_0) * \frac{g(x) - g(x_0)}{x-x_0} = f'(x) * g(x)$
