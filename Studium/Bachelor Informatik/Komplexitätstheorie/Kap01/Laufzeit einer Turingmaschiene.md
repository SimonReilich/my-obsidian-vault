# Definition
Eine [[Turingmaschiene]]  $M$ berechnet eine Funktion $f$ in Zeit $T$ wenn für jede Eingabe $x \in \{0, 1\}^*$ die berechnung von $f(x)$ höchstens $T(|x|)$ Schritte benötigt. Dabei muss $T$ eine [[zeitkonstruierbare Funktion]] sein.
