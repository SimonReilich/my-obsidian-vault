# Definition
Damit eine Funktion $T$ zeitkonstruierbar ist, muss sie folgende zwei Bedingungen erfüllen:
- es gibt eine [[Turingmaschiene]] $M$, die $T(n)$ in der [[Laufzeit einer Turingmaschiene|Zeit]] $O(T(n))$ berechnet
- $T(n) \geq n$
