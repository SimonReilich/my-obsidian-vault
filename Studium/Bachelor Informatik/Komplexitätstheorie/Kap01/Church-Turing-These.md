# Satz
Die Church-Turing-These (benannt nach [[Alonzo Church]] und [[Alan Turing]],) trifft Aussagen über die Fähigkeiten einer Rechenmaschine. Sie lautet:

> Die Klassse der turing-berechenbaren Funktionen stimmt mit der Klasse der intuitiv berechenbaren Funktionen überein.

Diese These ist nicht beweisbar, da der Begriff „intuitiv berechenbare Funktion“ nicht exakt formalisiert werden kann. Man versteht darunter alle Funktionen, die prinzipiell auf irgendeine Weise berechnet werden könnten. Damit setzt man insbesondere keine Vorstellung voraus, welche Funktionen auf den [[Natürliche Zahlen|natürlichen Zahlen]] berechenbar sind. Es wird in der Informatik üblicherweise angenommen, dass die These stimmt. Dadurch wird es möglich, für eine Funktion nachzuweisen, dass sie [[Entscheidbarkeit|nicht berechenbar]] ist.
