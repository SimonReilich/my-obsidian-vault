# Definition
Das Simple Mail Transfer Protocol (SMTP) ist ein textbasiertes Protokoll und dient dem Versenden von Emails, d. h. dem Transport vom Mail User Agent (MUA) zu einem Mail Transfer Agent (MTA), sowie dem Transport von Emails zwischen MTAs. In Empfangsrichtung werden i. d. R. [[Post Office Protocol]] (POP) oder [[Internet Message Access Protocol]] (IMAP) verwendet.
