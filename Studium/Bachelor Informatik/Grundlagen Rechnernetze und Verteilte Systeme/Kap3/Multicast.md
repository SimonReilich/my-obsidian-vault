# Definition
Vermittlungsart für Pakete ([[Rahmen]]), die an eine bestimmte Gruppe von Knoten adressiert sind. Die Adressierung erfolgt mittels spezieller Multicast-Adressen. Auf Schicht 2 werden Multicasts von [[Switch|Switches]] häufig wie Broadcasts behandelt. Auf Schicht 3 gibt es spezielle Protokolle , die Multicast-Adressierung auch über das lokale Netzsegment hinaus ermöglichen.
