# Definition
Ein Petrinetz, Netzsystem oder auch einfach nur System ist ein Paar $(N, M_0)$, wobei $N$ ein zusammenhängendes [[Netz]] (mit nicht-l) und $M_0$ eine initiale [[Markierung]] ist.

A Petri net, net system, or just a system is a pair (N, M0 ) where N is a
connected net N = (S, T, F ) with nonempty sets of places and transitions,
and an initial marking M0 : S → IN.
A marking M is reachable in (N, M0 ) or a reachable marking of (N, M0 ) if
∗
M0 −→ M .
