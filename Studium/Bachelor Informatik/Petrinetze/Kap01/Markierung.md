# Definition 
Sei $N = (S, T, F)$ ein [[Netz]]. Eine Markierung von $N$ ist eine Funktion $M: S \to \mathbb{N}$. Eine Stelle $s \in S$ ist markiert, wenn $M(s) > 0$. Eine Menge von Stellen ist markiert, wenn sie mindestens eine markierte Stelle enthält. Als Notation ist auch die Schreibweise als [[Vektor]] gebräuchlich. Graphisch kann eine Markierung auch als schwarze Punkte in einer Stelle dargestellt werden.
