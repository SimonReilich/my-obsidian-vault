# Notation
- $(a; b) = \{x \in \mathbb{R} : a < x < b\}$ offenes Intervall
- $[a; b] = \{x \in \mathbb{R} : a \leq x \leq b\}$ geschlossenes Intervall
- $(a; b] = \{x \in \mathbb{R} : a < x \leq b\}$ halboffenes Intervall ($[a; b)$ ist analog definiert)
