# Definition
Jede nicht leere, nach oben unten Teilmenge $M \subseteq \mathbb{R}$ besitzt eine kleinste untere [[Schranke]] $inf \space M \in \mathbb{R}$, das Infimum von $M$. Falls $inf \space M \in M$, so heißt $inf \space M$ auch Minimum von $M$.
