# Definition
Eine Folge $(a_n)_{n \in \mathbb{N}_0}$ komplexer Zahlen ist eine Abbildung $\mathbb{N}_0 \to \mathbb{C}, n \mapsto a_n$. Man schreit auch $a_0, a_1, a_2, ...$. Oft interessiert man sich für das asymptotische Verhalten einer Folge, genauer gesagt, ob eine gegebene Folge gegen einen Wert [[Konvergenz|konvergiert]] oder nicht.
