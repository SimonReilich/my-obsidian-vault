# Aussage
Für jede [[Monotonie|monoton]] wachsende [[Folge]] $(a n ) n∈N$ gilt
$$lim_
{n→∞} a_n = \sup
_{n∈\mathbb{N}}
a_n$$
Für jede [[Monotonie|monoton]] fallende [[Folge]] $(a n ) n∈N$ gilt
$$lim_
{n→∞} a_n = \inf
_{n∈\mathbb{N}}
a_n$$
Insbesondere ist jede [[Schranke|beschränkte]] monotone [[Folge]] konvergent und jede unbeschränkte monotone [[Folge]] ist uneigentlich konvergent gegen $±∞$.
