# Definition
Die [[Folge]] $a_n = (1 + {1 \over n})^n, n \in \mathbb{N}$ konvergiert. Der [[Konvergenz|Grenzwert]] $e = \lim_{n \to \infty}(1 + {1 \over n})^n = \sup_{n \in \mathbb{N}}(1 + {1 \over n})^n$ heißt Eulersche Zahl. Es gilt $e \approx 2,718...$.
