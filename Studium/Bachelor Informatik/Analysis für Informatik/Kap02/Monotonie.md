# Definition
Eine [[Folge]] $(a_n )_{n∈\mathbb{N}}$ reeller Zahlen heißt monoton wachsend, falls $a_n ≤ a_{n+1}$ für alle $n$,
und monoton fallend, falls $a_n ≥ a_{n+1}$ für alle $n$. Gilt sogar $a_n < a_{n+1}$ bzw. $a_n > a_{n+1}$ für alle $n$, dann heißt die [[Folge]] streng monoton wachsend bzw. streng monoton fallend.
