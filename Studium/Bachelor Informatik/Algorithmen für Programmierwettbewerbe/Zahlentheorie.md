# Große Integer
- definiere Ziffern zur Basis $b$: $\Sigma_b = \{0, 1, ..., b - 1\}$ 
- Zahl kann dann als Liste von Ziffern dargestellt werden: $x = x_n x_{n-1} ... x_0$
- Wert: $(x)_b = \Sigma_{i = 0}^n x_i * b^i$
