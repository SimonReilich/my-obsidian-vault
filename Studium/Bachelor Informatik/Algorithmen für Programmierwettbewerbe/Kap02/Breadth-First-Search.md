# Definition
BFS ist ein Algorithmus zur Traversion eines [[Graph|Graphen]]. Dabei werden entdeckte Vertecies in einer [[Queue]] gespeichert um dann nacheinander abgearbeitet zu werden. Damit ist er eine Variante von [[Depth-First-Search]].
BFS besitzt eine asymptotische Laufzeit von $O(|V| + |E|)$.
