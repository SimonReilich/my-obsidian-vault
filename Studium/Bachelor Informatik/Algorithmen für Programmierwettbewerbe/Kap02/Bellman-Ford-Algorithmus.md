# Definition
Der Bellman-Ford-Algorithmus ist eine Lösung für das [[Single-Source-Shortest-Path]]-Problem. Er wurde unabhängig von [[Richard Bellman]] und [[Lester Ford]] im Jahr [[1958]] bzw. [[1956]] veröffentlicht. Im Gegensatz zu [[Dijkstras Algorithmus]] löst er das Problem auch für negative Kantengewichte.
