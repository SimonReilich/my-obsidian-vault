# Definition
DFS ist ein Algorithmus zur Traversion eines [[Graph|Graphen]]. Dabei werden entdeckte Vertecies in einem [[Stack]] gespeichert um dann nacheinander abgearbeitet zu werden. Damit ist er eine Variante von [[Breadth-First-Search]].
DFS besitzt eine asymptotische Laufzeit von $O(|V| + |E|)$.
