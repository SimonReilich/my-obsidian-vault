# Definition
Ein monolithisches System ist eine Betriebssystemarchitektur, bei der das [[Betriebssystem]] vollständig im [[Betriebssystem-Modi|Kernel-Mode]] arbeitet. Der Betriebssystemkern hat eine hohe Ablaufpriorität und ist permanent im Arbeitsspeicher. Ein monolithischer Betriebssystemkern besitzt oft wenig Struktur, dadurch ist er schwer wart- und erweiterbar (Vergleiche Softwarearchitektur [[Monolithic]]).
