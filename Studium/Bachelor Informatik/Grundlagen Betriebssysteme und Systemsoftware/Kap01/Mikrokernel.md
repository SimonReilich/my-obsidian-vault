# Definition
Eine Betriebssystemarchitektur, bei der das [[Betriebssystem]] in kleine Module aufgeteilt wird, die einzelnen Systemprozesse sind eigenständig. Nur ein Modul, der Mikrokern läuft im [[Betriebssystem-Modi|Kernel-Mode]]. Dadurch dass der Kern deutlich kleiner ist als bei [[Monolithisches System|monolithischen Systemen]], ist das System deutlich leichter wartbar und Fehler werden isoliert (Vergleiche Softwarearchitektur [[Microservices Architektur]]).
