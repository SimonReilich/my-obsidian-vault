# Definition
Ein Prozess ist ein Programm in Ausführung, also eine aktive Einheit (Programm: passive Einheit). Ein Programm kann in mehreren Prozessen ausgeführt werden (genannt Instanzen des Programms). Ein System besteht aus einer Menge von Prozessen.
