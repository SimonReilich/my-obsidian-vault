# Definition
Ein dynamisches System lässt sich zu jedem Zeitpunkt durch eine Reihe von Eigenschaften, den Zustand des Systems, beschreiben. Dieser Zustand verändert sich über die Zeit, diese Folge von Zustandsänderungen beschreibt das Systemverhalten. Die Fähigkeit zur Zustandsänderung erhält ein System über aktive oder passive [[Komponenten]].
