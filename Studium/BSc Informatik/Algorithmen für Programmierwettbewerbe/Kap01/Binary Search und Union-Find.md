# Binary Search
- Algorithmus zum suchen von Elementen innerhalb eines Arrays
- Laufzeit: $O(n \log(n))$ 
- Kann auch genutzt werden, um Index $i$ zu finden, an dem $f(a_i) = x$ gilt (falls $i \mapsto f(a_i)$ [[monoton wachsend]] ist)
