# Beweis
Angenommen, $\mathbb{C}$ wäre [[Anordnung|angeordnet]]. Sei $a \in \mathbb{C}$.
- Falls $a > 0$, so soll nach Eigenschaft der [[Anordnung]] $a * a > 0$
- Falls $-a > 0$, so folgt analog $a² = (-a) * (-a) > 0$ 
Daraus folgt $a² > 0$ für alle $a \neq 0$. Für $a = i$ gilt allerdings $a² = i² = -1 < 0$. Das ist ein Wiederspruch.
