# Die Exponentialfunktion
- Definition [[Funktionalgleichung]] 
- Eigenschaften der Exponentialfunktion:
	- $exp(0) = \sum_{k = 0}^\infty {0^k \over k!} = {0^0 \over 0!} + {0^1 \over 1!} + {0^2 \over 2!} ... = 1 + 0 + 0 + ... = 1$ 
	- $exp(-z) = {1 \over exp(z)} \space \forall z \in \mathbb{C}$ (folgt aus der [[Funktionalgleichung]])
	- $exp(x) = \sum_{k = 0}^\infty {x^k \over k!} \geq {x^0 \over 0!} > 0 \space \forall x \in \mathbb{R}$ 
	- $exp(x) < exp(y) \space \forall x, y \in \mathbb{R}, x < y$ (folgt aus der [[Funktionalgleichung]])
	- $|exp(z)| \leq exp(|z|) \space \forall z \in \mathbb{C}$
